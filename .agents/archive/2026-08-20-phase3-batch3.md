# 阶段 3 第三批：Link 与 Loaders TypeScript 迁移

日期：2026-08-20

## 范围

本批次继续进行 JavaScript / JSX 到 TypeScript 的渐进迁移，处理三个低耦合公共组件：

- `Link`
- `LoaderBar`
- `LoaderBusy`

## 实施内容

- 删除三个组件的旧 `index.js`，新增对应 `index.tsx`。
- 为 `Link` 建立基于 React Router `LinkProps` 的显式 `LinkProps`，保留 `to="#"` 默认值、导航属性和旧 `className`/`style` 覆盖顺序。
- 为 `LoaderBar` 建立显式 `LoaderBarProps`，保留 `setTheme`、`isLoading`、四个 ball 节点和动画 class。
- 为 `LoaderBusy` 建立显式 `LoaderBusyProps` 与 `LoaderBusySize`，保留主题、尺寸、加载 class、内部 SVG wrapper 和根 `div` 原生属性透传。
- 更新三个组件的 public `.d.ts`、根声明入口和构建后的 `src/lib/dist` 文件。
- consumer 类型样例新增三组 Props 和 JSX 用法。
- 单元测试新增 Link 路由点击、LoaderBar 主题/加载状态、LoaderBusy 尺寸/主题/加载状态/原生属性覆盖；测试总数达到 21 个。

## 兼容性边界

- 未修改 SCSS、颜色、圆角、阴影、动画定义、DOM 层级或已有 class 名。
- 未删除旧 Props；`LoaderBusy` 的 `div` 原生属性支持属于声明补全，不改变运行时行为。
- 未复制或引入 Fluent UI 源码。

## 验证

以下命令均通过：

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm format:check`
- `pnpm build`
- `pnpm test:consumer`
- `pnpm --filter react-winui pack --dry-run`

构建仍输出既有 Dart Sass `@import` deprecation warning 与 docs 大 chunk warning；本批次没有处理这些非阻塞遗留项。
