# 阶段 3 第四批：AppContainer、ButtonGroup 与 SplashScreen TypeScript 迁移

日期：2026-08-20

## 范围

本批次继续进行 JavaScript / JSX 到 TypeScript 的渐进迁移，处理三个低耦合公共组件：

- `AppContainer`
- `ButtonGroup`
- `SplashScreen`

## 实施内容

- 删除三个组件的旧 `index.js`，新增对应 `index.tsx`。
- 为 `AppContainer` 建立显式 `AppContainerProps`，补齐运行时已经支持的 `style`，保留 Appearance 初始化和系统主题监听。
- 为 `ButtonGroup` 建立基于 `HTMLAttributes<HTMLDivElement>` 的 `ButtonGroupProps`，使用 `forwardRef<HTMLDivElement, ...>` 保留原生属性、事件和 ref。
- 为 `SplashScreen` 建立显式 `SplashScreenProps`，将 title、subtitle、logo 类型化为 `ReactNode`，保留默认值、定时可见状态、背景色和现有 DOM/class。
- 更新三个组件的 public `.d.ts`、根声明入口、consumer 类型样例和构建产物。
- 新增 AppContainer 主题/样式、ButtonGroup ref/事件、SplashScreen 内容/定时可见性测试；测试总数达到 24 个。
- 更新 format 脚本，使本批次 TSX 与声明进入持续格式检查。

## 兼容性边界

- 未修改 SCSS、颜色、圆角、阴影、动画定义、DOM 层级或已有 class 名。
- 未删除既有 Props；只将声明中遗漏的 `AppContainer.style`、`SplashScreen.logo` 和 ButtonGroup 的正确 DOM ref 能力显式化。
- 未复制或引入 Fluent UI 源码，也未处理下一批复杂组件。

## 验证

以下命令均通过：

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm format:check`
- `pnpm build`
- `pnpm --filter react-winui typecheck`
- `pnpm test:consumer`

构建仍输出既有 Dart Sass `@import` deprecation warning 与 docs 大 chunk warning；本批次没有处理这些非阻塞遗留项。
