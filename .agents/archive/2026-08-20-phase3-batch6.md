# 阶段 3 第六批：SelectNative 与 InputSearchBar TypeScript 迁移

日期：2026-08-20

## 范围

本批次继续进行 JavaScript / JSX 到 TypeScript 的渐进迁移，处理两个原生表单包装组件：

- `SelectNative`
- `InputSearchBar`

## 实施内容

- 删除两个组件的旧 `index.js`，新增对应 `index.tsx`。
- 为 `SelectNative` 建立 `SelectNativeOption` 与 `SelectNativeProps`，明确 option 的 `value`/`label`，并复用原生 select 属性和事件类型。
- 为 `InputSearchBar` 建立 `InputSearchBarProps`、`InputSearchValue` 与 `InputSearchSubmitHandler`，复用原生 input 属性并保留自定义搜索提交回调。
- 保留 `InputSearchBar` 的 `forwardRef<HTMLInputElement>`、默认 placeholder、宽度样式、按钮提交和原有 props spread 顺序。
- 更新 public `.d.ts`、根声明入口、consumer 类型样例、格式检查脚本和 `src/lib/dist` 构建产物。
- 新增 SelectNative 的 option/selection/disabled 测试和 InputSearchBar 的 change/submit/ref/disabled 测试；测试总数达到 30 个。

## 兼容性边界

- 未修改 SCSS、颜色、圆角、阴影、动画或 DOM 层级。
- 未删除已有 Props；将历史 `Function`/`any` 声明替换为原生事件和 value 类型。
- 未迁移自定义 `Select` 或带建议列表状态的 `InputSearchBox`，避免扩大本批次边界。

## 验证

以下命令均通过：

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm format:check`
- `pnpm build`
- `pnpm --filter react-windows-ui typecheck`
- `pnpm test:consumer`

构建仍输出既有 Dart Sass `@import` deprecation warning 与 docs 大 chunk warning；本批次没有处理这些非阻塞遗留项。
