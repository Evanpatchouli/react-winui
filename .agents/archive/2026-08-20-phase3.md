# react-winui 阶段 3（首批）

## 范围

本轮按渐进迁移原则处理五个基础组件：

- `Button`
- `InputText`
- `Checkbox`
- `RadioButton`
- `Switch`

## 完成内容

- 实现文件由 `.js` 改为 `.tsx`。
- 添加显式 Props 类型、原生 HTML 属性扩展、`forwardRef` ref 类型和公共 JSDoc。
- 保留原组件的 DOM 结构、className、默认行为和样式加载方式。
- `Button.value` 保留并标记 deprecated，同时支持 children。
- 更新组件声明文件和根入口的 Props 类型导出。
- 扩展 TypeScript 检查范围和 ESLint TSX 解析能力。
- 新增基础组件交互测试和 consumer 类型覆盖。

## 验证

```text
pnpm lint
pnpm typecheck
pnpm test
pnpm format:check
pnpm build
pnpm test:consumer
pnpm --filter react-winui typecheck
pnpm --filter react-winui pack --dry-run
```

## 遗留

- 其余公共组件仍为 JS + `.d.ts`，需继续按小批次迁移。
- Sass 仍会报告旧 SCSS `@import` 的 Dart Sass deprecation warning。
