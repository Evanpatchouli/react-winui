# 阶段 3 第五批：ColorPicker TypeScript 迁移

日期：2026-08-20

## 范围

本批次继续进行 JavaScript / JSX 到 TypeScript 的渐进迁移，处理 ColorPicker 的两个强相关子组件：

- `ColorPickerItem`
- `ColorPickerPalette`

## 实施内容

- 删除两个组件的旧 `index.js`，新增对应 `index.tsx`。
- 为 `ColorPickerItem` 建立显式 Props，类型化 radio 的 name、disabled、defaultChecked、change handler 和 swatch 尺寸。
- 为 `ColorPickerPalette` 基于原生 input 属性扩展 Props，排除内部控制的 type/value/change 属性，保留其它 rest props 透传。
- 将历史 `Function` 与 `any` 声明替换为 React 原生事件、CSSProperties 和字符串颜色类型。
- 保留两个组件的 label/input/div DOM 结构、现有 class、默认颜色 `#eee`、swatch 样式和 palette 内部颜色状态。
- 更新 public `.d.ts`、根声明入口、consumer 类型样例、格式检查脚本和 `src/lib/dist` 构建产物。
- 新增颜色 radio 与 color input 的状态、禁用、属性和 change handler 测试；测试总数达到 26 个。

## 兼容性边界

- 未修改 SCSS、颜色、圆角、阴影、动画或 DOM 层级。
- 未删除现有 Props；只收紧了历史 `Function`/`any` 声明并补充原生输入属性类型。
- 未复制或引入 Fluent UI 源码，也未进入 Select、Dialog、Menu 或 Nav 组件迁移。

## 验证

以下命令均通过：

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm format:check`
- `pnpm build`
- `pnpm --filter react-winui typecheck`
- `pnpm test:consumer`
- `pnpm --filter react-winui pack --dry-run`

构建仍输出既有 Dart Sass `@import` deprecation warning 与 docs 大 chunk warning；本批次没有处理这些非阻塞遗留项。
