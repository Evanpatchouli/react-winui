# react-winui 阶段 2

## 目标

整理 React 依赖、package exports、ESM、类型声明、tree-shaking 和 npm 发布结构，并建立最小 consumer 验证。

## 已完成

- `react` / `react-dom` peerDependencies 收紧为 `>=18`；`react-router-dom` 收紧为 `>=6`。
- 组件包补齐独立构建所需的 devDependencies，并保留 ESM + preserveModules 产物。
- 新增 `react-winui/button` 与 `react-winui/styles.css` exports，保留旧 CSS 路径。
- 收紧 `sideEffects`、`files` 和 `.npmignore`，通过 pack dry-run 验证发布包不包含开发源码。
- 组件包目录补入 MIT `LICENSE`，并在 pack dry-run 中确认会发布。
- 新增 `examples/test-app` workspace consumer，验证 root import、subpath import、类型和 CSS。
- React 18 consumer 及临时 React 19.2.8 consumer 均通过类型检查和 Vite build。

## 验证

```text
pnpm lint
pnpm typecheck
pnpm test
pnpm format:check
pnpm build
pnpm test:consumer
pnpm --filter react-winui pack --dry-run
```

## 遗留

- Dart Sass 仍报告旧 SCSS `@import` deprecation warning；为保持视觉不变，本阶段没有迁移 SCSS 模块组织。
